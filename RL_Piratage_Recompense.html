Le piratage de la récompense

Moulay Akhloufi

Une course de bateaux jouet, inspirée de l’exemple célèbre CoastRunners (OpenAI, 2016). Le vrai objectif : finir la course 🏁. La récompense donnée à l’agent : des points, +10 à l’arrivée, mais aussi +3 pour chaque bouée 🔵 touchée dans la lagune, et les bouées réapparaissent. Un agent Q-learning optimise exactement ce qu’on lui donne… pas ce qu’on voulait.

Le même problème dans les grands modèles de langage

Récompense mal spécifiée : un modèle de récompense qui aime les réponses longues ou flatteuses → des réponses verbeuses ou complaisantes (sycophancy).
Vérificateur trop faible : des tests unitaires incomplets → du code qui « passe » les tests sans résoudre le problème (par exemple en traitant les cas des tests à part).
Remèdes : pénalité KL vers le modèle de référence, meilleurs modèles de récompense, vérificateurs plus complets, évaluation humaine, récompenses combinées.
Loi de Goodhart : « quand une mesure devient un objectif, elle cesse d’être une bonne mesure ». La récompense n’est qu’un substitut de l’intention.
