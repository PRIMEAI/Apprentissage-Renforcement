Acteur-critique : l’avantage pas à pas

Moulay Akhloufi

Deux modèles apprennent ensemble. L’acteur πθ(a | s) choisit les actions ; le critique Vφ(s) estime ce qu’on peut espérer depuis chaque état. Après un épisode, chaque action est jugée par son avantage Aₜ = Gₜ − Vφ(sₜ) : a-t-elle fait mieux ou moins bien que prévu ? Acteur : θ ← θ + α Aₜ ∇ log πθ(aₜ | sₜ). Critique : φ ← φ − β ∇ ‖Aₜ‖².

ACTEUR : π(a | s) ET DERNIER ÉPISODE
CRITIQUE : V(s)

Récompenses : +10 au trésor, −10 dans le trou, 0 sinon ; γ = 0,95 ; épisode limité à 50 pas. Épaisseur des flèches : π(a | s).

À retenir

C’est REINFORCE avec une base de référence apprise : le critique fournit V(s). Avantage positif : l’action a été meilleure qu’attendu, on la renforce. Négatif : on l’affaiblit, même si la récompense était positive.
Variantes : on peut remplacer Gₜ par r + γ V(sₜ₊₁) (avantage TD, une mise à jour à chaque pas) ; A2C/A3C (plusieurs agents en parallèle), PPO (pas prudents), SAC (actions continues). Dans les LLM, PPO utilise un critique ; GRPO le remplace par la moyenne d’un groupe de réponses.
