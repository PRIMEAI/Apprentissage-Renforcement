Un modèle de langue vu comme un agent

Moulay Akhloufi

Générer une réponse, c’est un épisode de RL. État : l’invite et les jetons déjà générés. Action : le jeton suivant (≈ 100 000 actions possibles ; ici, 14). Politique πθ : le modèle de langue lui-même. Récompense : une seule, à la fin de la réponse (préférence humaine, modèle de récompense ou vérificateur). Ce mini-modèle apprend réellement par REINFORCE.

Invite : « Quelle est la capitale du Canada ? »

Apprendre avec la récompense

PROPORTION DE RÉPONSES CORRECTES (SUR 200 TIRAGES)

RL classiqueModèle de langue

action aₜprochain jeton
politique π_θ(a | s)le modèle de langue (softmax sur le vocabulaire)
épisodeune réponse complète
récompenseà la fin : préférence humaine, modèle de récompense ou vérificateur
Le pré-entraînement apprend à imiter du texte (supervisé). Le RL optimise ce qu’on veut vraiment (exactitude, utilité, sûreté) sans fournir la bonne réponse mot à mot : il suffit de savoir noter une réponse.
